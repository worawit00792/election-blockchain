# UBU Election System 2570 — Blockchain Edition

## วิธีรัน

### ขั้นที่ 1 — ติดตั้ง
```
npm install --legacy-peer-deps
```

### ขั้นที่ 2 — Compile Smart Contract
```
npx hardhat compile
```

### CMD ที่ 1 — รัน Blockchain
```
npx hardhat node
```

### CMD ที่ 2 — Deploy Smart Contract
```
npx hardhat run scripts/deploy.js --network localhost
```

### CMD ที่ 3 — รัน Web Server
```
node server.js
```

เปิดเว็บที่: http://127.0.0.1:3000
